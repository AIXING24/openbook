# 后端实施计划

版本：backend v0.3.1，2026-11-23。前端当前发布 v1.16.0。

前后端在 AIXING24/openbook 仓库维护。当前工作分支 dev/gaintrace-backend；前端仍由 GitHub Pages 发布，后端在隔离 Cloudflare 环境验证。原型保留在 prototypes/cloudflare-migration，正式实现放 backend，实施和验收证据放 docs/backend。

## 顺序与验收

1. 上传已有原型和报告：可在新 checkout 安装运行，无本机固定源码路径，无内嵌 Git、密钥或真实账本。提交须带版本号。
2. CPU 改造：交易逐条入库并索引；导入按小批次校验和提交；按账户、日期及必要的交易批次增量计算；失败、暂停和并发变更可恢复；所有片段完成后才确认每日点。保持旧格式、清仓记录、历史值、隐私百分比口径和近一年滚动保留。本地正确性检查后，在真实免费 Worker 验证 1000 笔/50 标的、冷启动和重复调用的 CPU；10ms 内应有余量。
3. 访问验收：先核查当前 workers.dev 默认解析问题，再测试可用的官方免费域名或已有自定义域名；保持 TLS 验证。手机 Wi-Fi 和蜂窝网络须实测。购买域名、新增付费方案另需用户明确授权。
4. 前端接入：通过带用户认证的接口读写云账本；保留原网址，首次上传先备份，分批暂存、核验后激活；本地缓存与持久化离线队列支持重试；旧快照保持原采集口径，新收盘记录与今日临时值分开。
5. 正式发布：前后端与旧备份兼容验证、模拟迁移和定时落库通过，确认行情日期、历史汇率与股票企业行动口径后，再启用真实账本迁移。不能把固定模拟行情或测试密钥直接用于真实账户。

## 当前证据

原型 v0.2.1 已验证云端迁移、隔离、幂等、并发、失败补算和实际 Cron；完整导入 CPU 出现 78.524ms、日计算两账户批次出现 16.665—27.055ms，当前尚未满足稳定免费运行要求。高频测试 Cron 已清空。

详细记录见 [云端验证](cloud-validation-2026-11-23.md)、[迁移方案](migration-plan.md)；新实施状态随阶段验收更新，避免把计划写成已经完成。

## 2026-11-23 实施进度

- 已上传原型和设计资料至现有仓库 dev/gaintrace-backend，归档提交 6ab7f75（backend v0.1.0）。不新增独立仓库。
- backend 已增加独立 gt_* 规范化表、分批验证后激活、带幂等/版本检查的交易操作，以及有持久化检查点的按日期增量计算。旧前端构建产物没有变化。
- 新后端 13 项本地检查通过，前端现有 34 项检查通过。覆盖清仓与完整旧历史、移动平均多空/手续费/分红、隐私百分比分母、原采集证据不变、竞争与失联重试、缺价格/FX待补、回溯归档和365日加基准保留。
- 独立 gaintrace-batch-validation Worker 已验证第一轮 8 个云端阶段、第二轮 4 个阶段。20条独立写入时出现22.007ms；合并 SQL 后，导入首次交易批次仍10.888ms、每日片段9.433ms、读取/幂等阶段7.143ms。不能据此宣布完全满足10ms；当前版本进一步把交易批次缩至10，继续实测。
- 云端固定行情/未来模拟日期保持明确标识；未启用真实账户、未改原手机页面、未迁移真实金融记录。测试 Cron 在实际观察后清空。
- 当前电脑将 workers.dev 解析为162.125.8.1，与官方 Cloudflare DoH 返回的地址不同；原域名 TLS 下使用正确地址可连接。未修改系统 DNS，手机 Wi-Fi/蜂窝访问待用户实测；该诊断通道不会安装进产品。

尚需核定整年历史读取/大备份容量和更多冷启动样本；正式 frontend 使用分页缓存同步、认证、市场日历、历史汇率、企业行动与恢复能力后再发布。云端小规模模拟通过不等于整个工具已完成后端切换。

- v0.3.0 将暂存上传和逐片校验分开，并合并日计算账户/任务查询。440次模拟调用验证通过；官方采样导入峰值5.649ms，但10标的估值首次调用出现11.872ms，仍不能宣布全流程满足免费CPU。v0.3.1将估值减为5标的，24次对应云端检查通过，对应官方统计峰值8.788ms、24次调用、0错误，当前样本低于10ms；仍需更多首次调用与整年历史分页验收。
- 用户反馈没有自有域名，手机蜂窝网络访问 workers.dev 空白；Wi-Fi暂无条件验证。准备了免费的Pages连接测试和同一模拟API产物，本地打包通过。Pages读取返回403（缺少pages:write），官方5分钟设备授权码过期，等待用户方便时重新授权。Pages尚未部署。
- 真实Cron已独立生成两个账户的模拟2026-11-24日终点；最后调度时间属于此前版本，不能当成新版本专属CronCPU验证。最终高频Cron清空，官方schedules=[]。真实前端与个人账本仍未切换。

下一性能步骤应先补可靠的调用级CPU证据和采样缺口，再评估是否需要分阶段定位或分批预算。没有把本轮纯合成复测扩大为真实Massive请求或永久源secret部署，也不建议用“没有运行时错误”替代免费CPU验收。

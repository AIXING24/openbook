## 本轮实现

- 新 `/api/ledger/` 使用服务端验证的邮箱身份 UUID 选择 `email:` 账本；原 alice/bob 账户及随机测试凭据保持隔离。登录身份不能通过请求参数或导入ID切换归属。
- 固定模拟账本分批上传、服务端逐段核验、客户端回读比对后激活；有云账本时直接读取，不替换已有数据。
- 页面联动持仓、清仓记录、买卖表单、同步状态及持久化操作队列；断网保存后重试同一操作ID和版本，401保留，409暂停并保留核对数据。支持导出待同步记录。
- 设置、交易和日终历史分页读取；每页及末页后核对账本版本。只读页数据和版本来自同次 SQL，避免并发修改造成页版本与内容不一致。
- 会话不写入本地账本或队列；测试版刷新仍需要重新登录。同一身份登录后恢复原缓存/待同步队列。正式登录续期体验仍待后续设计。
